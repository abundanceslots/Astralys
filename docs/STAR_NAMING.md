# Astralys — noms des étoiles

Les étoiles qui possèdent un nom commun ou une désignation scientifique vérifiée conservent ce nom dans l'application.

Les sources Gaia affichées auparavant sous la forme `Star 123…` reçoivent désormais un nom Astralys sans chiffre. Ce nom est généré de manière déterministe depuis l'identifiant Gaia : la même étoile conserve donc toujours le même nom sur tous les appareils et après chaque redémarrage.

Ces noms sont des alias d'interface propres à Astralys. Ils ne sont pas présentés comme des noms officiels de l'Union astronomique internationale. La fiche détaillée conserve la désignation scientifique et l'identifiant Gaia afin que l'objet réel puisse toujours être retrouvé et vérifié.

## Priorité d'affichage

1. nom commun fourni par le catalogue ;
2. nom commun vérifié dans les correspondances locales SIMBAD/CDS ;
3. désignation scientifique vérifiée ;
4. alias Astralys généré pour les identifiants Gaia purement numériques.

Les désignations scientifiques contenant légitimement des chiffres, comme `13 Lyrae`, ne sont pas remplacées.
