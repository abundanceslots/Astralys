## Implementation adaptations

The runtime satellite uses real Expo GL meshes and orbit inspection; no bitmap pretends to be a 3D viewer. The current model takes the middle ground between the clean revised mockup and the more photographic third concept: recognizable hardware and materials without cable-level visual noise. It has a structural silver bus, gold insulation and hinge collars, articulated booms, framed photovoltaic panels with broad cells, equipment housings, a lower circular module, sensor mast, tilted dish and feed horn. Distant system-map satellites use reduced geometry. No additional raster assets are necessary for the interactive subject. Approved logo, Sora and the existing icon library are reused.

The preview's balance200 corresponds to after collection. The demo still starts with balance80 and stored120, so the initial upgrade is disabled. The energy button opens a storage sheet, preserving collection and simulated time. The section shows only the next upgrade or completion; existing production, storage effects and prices remain unchanged. Explicit zoom, reset and expand controls supplement gestures and screen-reader actions. Full-screen viewing is dismissible; the main menu's four tabs remain unchanged. Small-screen/enlarged-text relay content can scroll without scrolling away the bottom navigation.
